Data Description 

Training Data 
- Historical resumes
- Job descriptions
- Past hiring decisions (labels)

Data Risks
- Historical bias in hiring outcomes
- Gendered or culturally biased language
- Sensitive personal data (names, addressed, phone numbers)
  
Data Processing
- Tokenization using WordPiece (BERT tokenizer)
- Removal of sensitive data
- Rebalancing of underrepresented groups
 
 Data Governance Requirements
- Data lineage documentation
- Access control and encryption
- Compliance with employment and privacy laws
