BERT Governance & Risk Assessment 

This repository contains a full AI Governance assessment for a real open-source model:
**BERT (Bidirectional Encoder Representations from Transformers)**, developed by Google Research.

The assessment includes:
- System description
- Data governance analysis
- Impact assessment
- Risk register
- Governance controls
- Bias & drift monitoring
- EU AI Act classification
- Full case study

Model reference:
BERT is a transformer-based, bidirectional language model that generates contextual embeddings and
supports tasks such as classification, question answering, and feature extraction.
